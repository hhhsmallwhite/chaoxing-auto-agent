# 手机遥控 AI 刷课：DSH + 豆包全自动过学习通

> 人在外面用手机发一句话 → 家里的 DSH 收到 → DSH 去催豆包 → 豆包自己一节一节刷完视频和章节测验。

一套完整、可复现的**双层 Agent 遥控**方案。不是概念，是实测跑通了 5 个章节、40+ 小节的真实记录。

## 这套东西解决什么问题

你有一门学习通网课要刷，几十个小节，每节十几分钟视频加一道测验。手动刷要十几个小时。

你想的是：**能不能让它自己跑，我人在外面用手机瞄一眼就行？**

这个仓库就是答案。分三层：

| 层 | 谁 | 干什么 |
|---|---|---|
| 遥控层 | 手机上的 DSH Remote | 你在外面发一句话 |
| 指挥层 | DSH（电脑） | 理解意图、检查进度、催豆包 |
| 执行层 | 豆包「任务模式」 | 真的去点网页、播视频、答题 |

**关键认知**：DSH 不刷视频，它只负责**催豆包干活**。真正刷课的是豆包。搞不清这个分工，后面会一直绕。

## 快速开始（三步）

### 1. 让豆包开始刷

豆包切到**任务模式**，发：

```
<你的学习通课程链接>

你进去之后帮我刷视频。
每个小节里面有两部分：第一部分是视频，第二部分是章节测验。
每完成一个小节，先把视频看完，再把对应的测验做了，做完刷新一下页面确认这个节变成"已完成"，再点下一个节点。
一直挂在后台看着，一节一节往下推进。
```

### 2. 让 DSH 能催它

```powershell
# 检查状态
powershell -ExecutionPolicy Bypass -File scripts/check-doubao.ps1

# 发「继续」
powershell -ExecutionPolicy Bypass -File scripts/send-jixu.ps1
```

两个脚本开箱即用，路径在文件开头改一行就行。

### 3. 手机遥控 DSH

装 `ds-harness-remote` 插件 → 登录 → 扫码配对 → 手机上就能发话了。

详细步骤见 **[完整手册](docs/GUIDE.md)**。

## 你必须知道的三个坑

这三个是我实际踩过的，不看你一定会重踩。

### 坑 1：倍速不能开，必须 1 倍

学习通按**真实观看秒数**上报，服务端累加。

> 实测：2 倍速播了 20 分钟，页面显示"已看完"，但服务端只记录了 **51%**，任务点不通过。

所以防暂停脚本里 `window.__RATE` 必须是 `1`。想省时间反而白刷。

### 坑 2：豆包刷完一章就会停，不会自己往下跑

它每刷完一章就输出一份总结，然后说：**"你回「继续」，我就接着从 X.1 开始。"**

它停下时的特征：
- 沙箱里没有 Python 任务在跑
- 轨迹日志停止写入
- 在等你的下一句话

**所以整套流程的核心就是"每隔 1–1.5 小时发一次继续"。** 这也是为什么需要 DSH 来自动化这件事。

### 坑 3：锁屏状态下，普通方式打不进字

电脑锁屏时：截图全黑、鼠标点不动、`SendInput` 失效、`SetForegroundWindow` 被拒。

得绕过输入系统，直接往窗口投递消息。而且有个非常阴的细节：

> **`WM_CHAR` 的 wParam 不是 Unicode 码点。**
> Chromium 会按当前代码页（GBK）解释它，直接发 `U+7EE7`（继）会变成「鐍」。

正确做法是把字符编成 GBK 字节，再按 `低字节 + 高字节 × 256` 拼成 wParam：

```
"继" → GBK = BC CC → wParam = 0xCCBC
"续" → GBK = D0 F8 → wParam = 0xF8D0
```

完整可用的脚本在 [`scripts/send-jixu.ps1`](scripts/send-jixu.ps1)，直接跑就行。

### 三种使用方式，按省心程度递增

| 方式 | 怎么做 | 适合 |
|---|---|---|
| **手动** | 想起来了就跑一下 `check-doubao.ps1`，停了再跑 `send-jixu.ps1` | 试试看 |
| **半自动** | 手机遥控 DSH，发一句"看下豆包停了没，停了让它继续" | 日常用 |
| **全自动** | 后台跑 `watchdog.ps1`，它自己判断、自己发 | 睡觉/出门 |

`watchdog.ps1` 的判定逻辑：

```
每 60 秒检查一次
  ├─ 沙箱进程数 = 0 ?          ── 没在干活
  ├─ 日志静默 > 3 分钟 ?        ── 确实停了（视频监控约 2 分钟写一次）
  └─ 距上次发送 > 10 分钟 ?     ── 冷却中，防止狂发
        ↓ 三个都满足
     调用 send-jixu.ps1 发「继续」
        ↓ 等 90 秒
     确认沙箱进程数变成 1 → 记 OK
     否则 → 记 ERROR，提示排查
```

跑法：

```powershell
# 后台常驻（推荐）
Start-Process powershell -ArgumentList '-NoProfile','-ExecutionPolicy','Bypass','-File','watchdog.ps1' -WindowStyle Hidden

# 前台看实时输出（调试用）
powershell -ExecutionPolicy Bypass -File scripts/watchdog.ps1 -Verbose
```

全程写 `watchdog.log`，可以事后查它什么时候发了、发了几次、成没成。

## 常见问题

**Q: 豆包不动了怎么办？**
先看是不是刷完一章在等你。跑 `check-doubao.ps1`，它会告诉你结论。八成就是等你说「继续」。

**Q: 视频在播但任务点不涨？**
用了倍速。改回 1 倍速重播这一节。

**Q: 输入框里出现乱码「鐍韣」？**
wParam 用了 Unicode 码点。改成 GBK 打包。

**Q: 手机连不上电脑？**
检查 DSH 是否在跑、Remote 面板是否显示在线、两边是否同一账号。

更多问题见 [GUIDE.md 第四部分](docs/GUIDE.md#第四部分故障排查)。
